# Movie-recommendation-system

A Movie Recommendation System is an intelligent software application designed to suggest movies to users based on their interests, preferences, and viewing behavior.

## Frontend web app

This repository now includes a Streamlit frontend (`app.py`) with:
- animated floating gradient bubbles
- neon/glassmorphism hero layout
- upload controls for Python script and dataset files
- interactive genre + energy controls
- a result stage panel ready to connect with backend recommendation logic

### Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
